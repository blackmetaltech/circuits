# ngspice reference CSVs (DESIGN 9.2)

Generated by `scripts/ngspice-ref/run.sh` from the decks in `scripts/ngspice-ref/` (ngspice-47, see `ngspice-version.txt`). Committed so CI needs no ngspice.
Header row = column names with units, first column = time / sweep variable / frequency. Transients are resampled to a uniform grid (<= 2000 rows).
Models: Shockley diodes, Ebers-Moll BJT (no capacitances), Level-1 MOSFET + explicit body diode, ideal switch, TRAP, reltol 1e-5 abstol 1e-12 vntol 1e-7 gmin 1e-12.
`python3 -I scripts/ngspice-ref/summarize.py` prints every number below from the CSVs. Time columns are absolute from power-on (sources start at phase 0 at t = 0).

## Known differences to keep in mind when comparing NODE

- **Early effect.** ngspice scales the transport current by 1/(1 - Vbc/Vaf) = 1/(1 + (Vce - Vbe)/Vaf); DESIGN 3.3 writes (1 + Vce/Vaf). That is about Vbe/Vaf = 0.9 % in Ic at Vaf 74. Decks 6, 13, 15 use Vaf 74 as asked. Deck 6 also carries `v_out_noearly_V` (Vaf infinite), which both solvers define identically (gain 9.560 vs 9.523 with Early). If NODE's formulation differs, compare deck 6 against the no-Early column with Vaf = infinity, or align NODE to the SPICE form.
- **Diode breakdown.** NBV = 1, IBV in the card, ngspice shifts its internal knee so that I = IBV exactly at Vd = -BV: the same law as DESIGN 3.3 (I_bv = -Ibv exp(-(Vd+BV)/(Nbv Vt))). Zener Is 1e-14, N 1 and Rs 6.47 (= Zzt 7 ohm minus 0.53) are estimates (DESIGN gives only BV, Ibv, Rs "fit to Zzt"). 1N4007 IBV 1 mA is the SPICE default, never reached.
- **Body diode** of the 2N7000 (Is 1e-13, N 1, Rs 0.5) is an estimate (DESIGN gives no numbers). It is not forward-biased in decks 7/8. ngspice's MOSFET is symmetric (source and drain swap if Vds < 0); the explicit body diode is separate.
- **cshunt = 1 pF** (ngspice-only numerical aid) in decks 3, 13, 14: without it ngspice aborts with "timestep too small" at the floating-bridge / regenerative-BJT switching instants, with any method. Checked against 0.1 pF: deck 3 v_out differs by < 10 uV, deck 14 means/ripples unchanged to 5 digits, deck 13 frequency 1459.99 vs 1460.04 Hz. NODE has no shunt capacitance.
- **Floating transformer secondary** (decks 3, 14): the AC side of the bridge has no ground reference, as in NODE (gmin only).
- **Op-amp** (decks 10, 11) is an ideal VCVS (gain 1 and 1e6), i.e. compare against NODE's "ideal" op-amp variant, not the 741 / TL072 macro.
- **Start-up.** ngspice applies DC sources as a hard step at t = 0; NODE ramps them over 1 us (DESIGN 3.5). Deck 9 includes the 1 us ramp explicitly; decks 12 and 13 are compared in steady state / frequency only. Deck 13 uses a 5 % capacitor asymmetry so the start-up side is deterministic (a symmetric circuit from an all-zero start never leaves its metastable point in exact arithmetic).
- **Constant-current load** (deck 14) is an ideal current source, also at t = 0 when the capacitor is empty (the output dips slightly negative for the first moments of the power-on run, not visible in the settled CSVs).
- **Thermal voltage.** `temp = tnom = 26.85 C` gives T = 300.00 K. ngspice's Vt = 25.852 mV (`00-vt-check.cir`; CODATA-2018 kT/q = 25.85200 mV), so it matches NODE's 25.852 mV to 5 digits. (Older ngspice builds with the pre-2018 constants give 25.851 mV, about 0.003 % lower.) With temp = tnom, Is and Eg are not temperature-scaled.
- Suggested comparison tolerances follow DESIGN 9.2: transient max |delta| <= 0.5 % of the reference range, AC 0.1 dB / 0.5 deg. Decks 11 and 13: frequency only (decks 11: 2 %; 13: 2 %).
